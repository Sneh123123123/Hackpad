# Hackpad / Macropad

A compact, USB-programmable custom hackpad using the Seeed Studio XIAO MCU. This device features a 4-button layout, a rotary potentiometer, an OLED graphic display and an audio module for tactile, multimedia, and automation control.

## Hardware Specifications

- **Microcontroller:** Seeed Studio XIAO (SAMD21)
- **Components:** 
  - 4 x Buttons
  - 1 x Rotary Potentiometer 
  - 1 x Audio Module
  - 1x OLED Graphic Display

## Core Features

- **Macropad Buttons:** 4 programmable buttons mapped to keyboard shortcuts, app launches, or dev tools (or whatever you want). 
- **Rotary Potentiometer:** Rotary potentiometer for smooth scrolling, volume control, or brush resizing.
- **Audio Module:** Audio module for status chimes, error beeps, or cool sound effects.
- **Pocket-Sized:** Minimalistic layout using the ultra-small Seeed Studio XIAO footprint.
- **OLED Graphic Display:** A Graphic Display for cool illustrations, animations and displays.

## Software & Firmware Setup

### Preparation
1. Download and install the [Arduino IDE](https://arduino.cc).
2. Add Seeed Studio boards to your IDE manager using the official guide.


### Installation
1. **Clone this repository:**
   (Yet to Add)
2. **Open the project:** Launch Arduino IDE and open `...`.
3. **Select Board:** Go to Tools > Board and select your specific Seeed Studio XIAO model.
4. **Upload:** Click the upload button to flash the firmware to your hackpad.
